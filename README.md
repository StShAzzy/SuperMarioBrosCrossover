# SuperMarioBrosCrossover 3.1.22

A modification of Super Mario Bros. Crossover 3.1.21
With the main focus of running independent of any webservers (currently using this repository to retrieve data)
And only after that consider any more changes

# How to Play

Run the file [`smbc-patched.swf`](https://placeholder.com) in Ruffle or Flash Projector
