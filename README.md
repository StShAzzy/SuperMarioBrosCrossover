# SuperMarioBrosCrossover 3.1.22

A modification of Super Mario Bros. Crossover 3.1.21<br>
With the main focus of running independent of any webservers (currently using this repository to retrieve data)<br>
And only after that consider any more changes

# How to Play

You can either download from the [Releases tab](https://github.com/StShAzzy/SuperMarioBrosCrossover/releases) and setup the sandbox permissions to allow Local-With-Online<br>
Or open from [`https://stshazzy.github.io/smbc-3.1.22-compressed.swf`](https://stshazzy.github.io/smbc-3.1.22-compressed.swf)
